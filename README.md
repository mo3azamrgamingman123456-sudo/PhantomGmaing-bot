# PhantomGmaing-bot

واجهة أولية لمنصة استضافة بوتات Discord فقط.

## ما الموجود حاليًا؟
- لوحة تحكم عربية RTL.
- بطاقات متعددة لمشاريع البوتات.
- نموذج إنشاء مشروع تجريبي.
- حالات تشغيل تجريبية داخل الواجهة.
- تصميم متجاوب للكمبيوتر والموبايل.

## ما الذي لم يتم توصيله بعد؟
هذه نسخة واجهة (Frontend prototype) وليست خدمة استضافة فعلية. لا يوجد حاليًا:
- تسجيل حسابات حقيقي.
- رفع ZIP إلى تخزين سحابي.
- حفظ دائم للمشاريع.
- حفظ آمن لـ Discord Bot Tokens.
- خادم يشغّل عمليات البوتات أو يعرض سجلات حقيقية.
- نظام دفع أو باقات.

## التشغيل محليًا
```bash
npm install
npm run dev
```
ثم افتح http://localhost:3000

## النشر
يمكن رفع المشروع إلى GitHub ثم استيراده إلى Vercel. نشر الموقع لا يشغّل عمليات Discord Gateway؛ تشغيل البوتات يحتاج خدمة Worker/Runtime منفصلة تدعم عمليات مستمرة.

## الأمان
لا تضع Discord Bot Token في كود الواجهة أو متغيرات `NEXT_PUBLIC_` أو GitHub. يجب إضافة التوكن لاحقًا من خلال API server-side وتخزين أسرار مشفر ومقيّد الصلاحيات. لا تشغّل ملفات العملاء مباشرة على نفس الخادم دون عزل قوي وحدود موارد.

## مراحل التطوير المقترحة
1. ربط تسجيل الدخول وقاعدة البيانات.
2. إضافة تخزين ملفات المشاريع ورفع ZIP.
3. بناء خدمة تشغيل منفصلة مع عزل لكل بوت وحدود CPU/RAM.
4. إضافة إدارة الأسرار والسجلات وإعادة التشغيل.
5. إضافة الباقات والدفع بعد تحديد مزود مناسب.
